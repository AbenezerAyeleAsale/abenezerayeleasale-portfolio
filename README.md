# Abenezer Ayele Asale — Portfolio Website

Production-ready responsive single-page portfolio built with HTML5, CSS3 and vanilla JavaScript.

## Files

- `index.html` — semantic page structure, SEO metadata and all portfolio content
- `styles.css` — responsive styling, banking color system, dark mode, animations and mobile navigation
- `script.js` — dark/light mode, mobile menu, scroll progress, reveal animations, skill bars, certification filters and frontend-only contact form
- `assets/profile.png` — supplied profile image
- `assets/Abenezer_Ayele_CV.pdf` — supplied CV, used by the Download CV button

## Run locally

Open `index.html` in a modern browser, or serve the folder through any static web server.

Example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

The folder can be deployed directly to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or another static hosting service.

## Notes

- No JavaScript framework is required.
- Google Fonts is the only external font dependency.
- The contact form is frontend-only and opens the visitor's email application via `mailto:`.
- Replace/update the CV file in `assets/` whenever a newer version is available.
